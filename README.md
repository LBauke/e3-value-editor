# e³value Editor

Ein Editor zum Modellieren von e³value-Wertnetzwerken im Browser.

- Notation: Akteur, Marktsegment, Wertaktivität, Wertschnittstelle, Wertport, Wertaustausch mit Wertobjekt, Start- und Stopp-Stimulus, Verbindungselement
- Geführte Bedienung mit Syntaxregeln und laufender Modellprüfung
- Speichern und Öffnen als JSON, Export als PNG und SVG

## Nutzung

Den Editor über die Projektseite im Browser öffnen oder `e3value-editor.html` herunterladen und per Doppelklick starten. Es ist keine Installation nötig; die Datei funktioniert auch offline.

Modelle werden nur lokal gespeichert (im Browser bzw. als `.e3v.json`-Datei).
